# Coffee--sales-shop-analysis-EXCEL

**About**
A Coffee Shop Sales Analysis project using Microsoft Excel, where I worked with transaction-level sales data to understand business performance and identify useful insights.

**KPI's**
1. Monthly sales trends: Which months generated more or less revenue.
2. Peak sales hours: When the coffee shop received more transactions.
3. Product performance: Which products or categories contributed more to sales.
4. Revenue performance: How much money the shop generated over the analyzed period.
5. Customer purchasing patterns: How transaction activity varied by time and product.

**Concepts used**

1. Data cleaning and preparation
2. Sales and transaction analysis
3. Pivot Tables & Pivot Charts
4. Filtering and sorting data
5. Monthly and hourly sales analysis
6. Identifying sales trends and patterns
7. Creating an interactive dashboard
